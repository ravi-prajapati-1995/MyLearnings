Machine Learning Development life cycle
1. Framing the problem
2. Gathering data
    Data can be gather in different ways i.e CSV, API, Web scrapping, Datalake(ETL), Spark Cluster
3. Data Preprocess:
    remove Duplicates, Remove missing values, Remove outlier, Scale value
4. Exploratory Data analysis(EDA):
    In this step we do analysis of data by visualization
    We do univariate / Bivariate
    Outlier detection
    imbalance dataset handle
5. Feature Engineering and selection: he process of creating new data features or transforming existing ones to help
    machine learning models perform better

6. Model Training, Evaluation and selection: In this phase we will give our data to multiple algorithm and check which is
    performing better, Then evaluate the result from different models

7. Model Deployment:
8. Beta Testing: Will do the A/B testing
9. Optimize
